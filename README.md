# 智能送药小车

2021 全国大学生电子设计竞赛 F 题：智能送药小车。

STM32F103C8T6 + K230 AI 摄像头，沿黑线巡线，经十字/T字路口，自动识别病房数字（1~8），自主导航送药并返程。

---

## 硬件

```
STM32F103C8T6
├── 8路灰度传感器      → 黑线巡线 + 十字/T字路口检测
├── MPU6050 (陀螺仪)    → 转弯角度控制（卡尔曼融合）
├── HMC5883L (磁力计)   → 偏航角观测（卡尔曼融合输入）
├── 2路编码器电机       → PID 速度闭环 + 差速转弯
├── K230 AI摄像头       → UART1 115200bps 数字识别
├── OLED 128x64 (I2C)  → 调试显示
└── PB5 药物检测        → 放药启动 / 取药返程
```

## 项目结构

```
├── code/               ← 应用层（PID控制、导航状态机、传感器）
├── ml_libs/            ← STM32 外设驱动库
├── sys/                ← CMSIS 系统文件
├── user/               ← 入口文件 + Keil 工程
├── det_uart.py         ← K230 端数字识别脚本
└── 2021F_智能送药小车.pdf  ← 竞赛题目
```

## 编译与烧录

1. 打开 `user/Project.uvprojx`（Keil MDK v5）
2. 编译器：ARMCC V5.06 update 7
3. 目标芯片：STM32F103C8
4. Build → `user/Objects/Project.hex`
5. ST-Link 烧录 HEX 到 STM32

## 导航逻辑

小车从起始区出发，沿黑线巡线：
- **病房 1、2**：第1路口两侧（固定位置）
- **病房 3~8**：第2路口由 K230 摄像头识别数字，动态决策方向（左转/右转/直行）
- **远端病房**：直行后进入大T→小T路口，K230 识别卡牌数字定位目标病房
- **返程**：取药后自动记录路径，倒序返回

## 调试开关（main.c）

| 宏 | 作用 |
|----|------|
| `DEBUG_FORCE_DEST` | 强制锁定目的地(1~8)，0=正常 |
| `K230_DEBUG` | 上电后显示 K230 原始检测数据 |
